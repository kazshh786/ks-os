# Definition of Done

A migrated feature is complete only when:
- the UI uses real routes and real data;
- request and response payloads are validated;
- tenant and role permissions are enforced server-side;
- loading, empty, success, and error states exist;
- automated tests cover critical business rules;
- the feature is manually verified in a browser;
- no credentials or personal data are stored in localStorage;
- the legacy equivalent remains available until cutover is approved;
- documentation and the decision log are updated.
