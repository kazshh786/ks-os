# Project Brief

KS OS is a multi-tenant salon operating system covering public booking, staff operations, reception, CRM, POS, consent forms, business configuration, and an agency control plane.

The redesign is the desired UX and product direction. The current Next.js application is the source of proven backend logic, database integration, authentication, tenant checks, booking rules, domain handling, and API security.

The migration must combine both without a big-bang rewrite.
