# Source Folders

## 01-current-next
Use it to identify:
- Supabase authentication flows;
- Drizzle schema and migrations;
- API routes and service logic;
- tenant and role checks;
- booking availability and lifecycle rules;
- domain/subdomain validation;
- rate limiting and webhook behaviour;
- existing tests.

## 02-redesign-vite
Use it to identify:
- visual language and layout;
- staff workspace navigation;
- agency control-plane UX;
- reception workflows;
- CRM, POS, forms, and calendar interaction patterns;
- reusable components and styles.

Do not copy its localStorage data engine or hard-coded login into production code.
